В этом проекте используется модель MVC (Model-View-Controller). Вот краткое описание пакетов и их взаимодействия:

### Пакеты

1. **`controller`**:
   - **Описание**: Этот пакет содержит контроллеры, которые управляют взаимодействием между моделью и представлением.
   - **Классы**:
     - `SimulaattorinController`: Управляет основным интерфейсом симулятора, обрабатывает пользовательские действия и обновляет представление.
     - `HelpController`: Управляет окном помощи.
     - `ResultsController`: Управляет окном результатов симуляции.
     - `Kontrolleri`: Основной контроллер, который управляет запуском и остановкой симуляции.
     - `IKontrolleriForV`: Интерфейс для контроллера, предоставляющий методы для управления симуляцией.

2. **`view`**:
   - **Описание**: Этот пакет содержит классы, отвечающие за графический интерфейс пользователя (GUI).
   - **Классы**:
     - `SimulaattorinGUI`: Основной класс приложения, который запускает GUI и связывает его с контроллером.

3. **`simu.framework`**:
   - **Описание**: Этот пакет содержит основные классы и интерфейсы для симуляции.
   - **Классы**:
     - `Moottori`: Абстрактный класс, представляющий движок симуляции.
     - `Kello`: Синглтон, представляющий часы симуляции.
     - `Tapahtumalista`: Класс, представляющий список событий в симуляции.
     - `Tapahtuma`: Класс, представляющий событие в симуляции.
     - `Saapumisprosessi`: Класс, представляющий процесс прибытия в симуляции.
     - `Trace`: Класс для логирования сообщений с различными уровнями серьезности.
     - `ITapahtumanTyyppi`: Интерфейс для типов событий.
     - `IMoottori`: Интерфейс для движка симуляции.

4. **`simu.model`**:
   - **Описание**: Этот пакет содержит классы, представляющие модель данных симуляции.
   - **Классы**:
     - `OmaMoottori`: Конкретная реализация движка симуляции.
     - `Asiakas`: Класс, представляющий клиента в симуляции.
     - `newCustomer`: Класс, представляющий построитель для создания новых клиентов.

5. **`dao`**:
   - **Описание**: Этот пакет содержит классы для доступа к данным.
   - **Классы**:
     - `SimulationResultDao`: DAO для управления результатами симуляции.

6. **`datasource`**:
   - **Описание**: Этот пакет содержит классы для управления подключением к базе данных.
   - **Классы**:
     - `MariaDbJpaConnection`: Синглтон для подключения к базе данных MariaDB с использованием JPA.

7. **`entity`**:
   - **Описание**: Этот пакет содержит классы сущностей для базы данных.
   - **Классы**:
     - `SimulationResult`: Класс, представляющий результат симуляции.

### Взаимодействие

- **Контроллеры** (`controller`): Обрабатывают пользовательские действия и обновляют представление. Они взаимодействуют с моделью для выполнения бизнес-логики и получения данных.
- **Представление** (`view`): Отображает данные пользователю и отправляет пользовательские действия контроллерам.
- **Модель** (`simu.model` и `simu.framework`): Содержит бизнес-логику и данные симуляции. Взаимодействует с контроллерами для выполнения операций и предоставления данных.
- **DAO** (`dao`): Обеспечивает доступ к данным и взаимодействие с базой данных.
- **Datasource** (`datasource`): Управляет подключением к базе данных.
- **Entity** (`entity`): Определяет структуру данных, хранящихся в базе данных.
